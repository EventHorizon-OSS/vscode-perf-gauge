# VS Code Performance Gauge

A starter project for a Visual Studio Code extension focused on editor
performance. The extension currently provides a **Show Performance Gauge**
command as a starting point for future functionality.

## Development

1. Install dependencies with `npm install`.
2. Run `npm run compile` to build the extension.
3. Press **F5** in VS Code to launch the Extension Development Host.
4. In the Extension Development Host, run **Show Performance Gauge** from the
   Command Palette.

Run `npm run test:unit` for unit tests or `npm run test:integration` for
extension-host integration tests. Run `npm test` to run both.
